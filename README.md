# Watch Together

A mobile-first Watch Together app for private rooms, service launchers, channel-guide shortcuts, and discreet non-blocking sponsorship placements.

The channel guide is a navigation layer: selecting a channel opens the user's authorized provider service. It does not bypass DRM, authentication, subscriptions, or provider restrictions.

## Development
```
npm install
npm run dev
```


## Ready to share
Create a room, tap **Invite**, and send the generated room link through Messages, Messenger, email, or your device's share menu.
